# 药物资料与分类整理计划

## 基线和本次交付

2026-11-05 的离线库合并后有 595 个稳定身份，包括本次新增的盐酸苯海索。主临床资料包 347 条，其余 248 条保留在基础包。历史名称和 ID 不变。新增条目的口服途径、适应证、禁忌、警告及相互作用依据 DailyMed 说明书；ATC N04AA01 只用作分类依据，不把 DDD 当作个人剂量。

本次同步统一底栏图标和文字布局，删除激素曲线下的记录计数；分类标签去掉 B01、C01 等编码，加入神经系统用药、抗帕金森药和抗胆碱药。内部分类 ID 保留，旧筛选和记录关联无需迁移。完整资料补齐和分类层级改造按下列计划继续，不把本次新增一个条目视作全库核验完成。

## 补齐顺序和验收

1. **身份与来源**：先核对 HRT 全部成分、酯、制剂和途径，再处理精神科、心血管及其他药物。逐项确认中文名、英文名、盐/酯、复方、品牌及规格；别名不能把不同身份合并。修复未定义分类，人工审阅歧义别名。每批 10–20 条，保留原 ID 和名称映射。
2. **临床资料**：优先监管说明书和当地批准信息，其次指南及原始研究。逐药补适应证、禁忌、重要警告、相互作用、监测和途径；注明来源、版本、适用地区及核验日期。不同制剂分开核实。缺乏依据的数值保持空白；不把另一药的通用模板当作已核实资料。
3. **剂量和时间资料**：明确适应证、人群、剂型、计量成分与单位；PK、临床起效、持续时间分别描述。不把血浆半衰期当作疗效持续时间，不把 ATC DDD 写入服药建议。模型参数继续独立版本化，不因文案整理而改变历史曲线。
4. **面向用户的文字**：删去资料摘要中的开发说明、学习用途、模型字段名和重复研究提示；使用“用途、注意事项、相互作用、监测、资料来源”等短标题。技术审阅状态移入维护数据，来源和限制放入详情。保留真实禁忌、不良反应、尚无可靠数据及估算性质；不可用删除提示掩盖资料缺口。候选文字逐条核对，不用全局替换删除“研究”二字。
5. **双语及验证**：英文和中文共用身份及引用，翻译核对成分、剂量单位和否定句。每批运行 ID/别名/分类/单位/引用检查，再抽查物质详情和原记录查找。全部 595 项都有明确的“已核实/不适用/待核实”清单及直接来源，才称全库整理完成。

## 更清楚的分类方式

界面采用“用途大类 → 药物类别”，途径、剂型作为独立筛选：

| 用途大类 | 类别示例 |
| --- | --- |
| HRT 与内分泌 | 雌激素、抗雄激素、孕激素、GnRH 类、其他内分泌用药 |
| 精神与神经系统 | 抗抑郁、抗精神病、心境稳定、抗焦虑、睡眠、ADHD、抗帕金森、其他神经用药 |
| 心血管与血液 | 抗血栓、血压、心律、心衰、血脂、外周循环 |
| 其他药物与物质 | 按现有资料保留相应类别，允许多重归类 |

抗胆碱等作用机制作为辅助标签；处方属性、收藏、最近使用不与治疗类别混排。ATC 作为内部映射和详情信息，不在类别标题显示编号；类别名称遵循统一的“抗血栓药”等用语。

实施分两步：先建立稳定分类 ID 到父类、显示名、排序和旧分类的映射表；再把当前平铺筛选改成大类选择与类别筛选。去重 `antithrombotic` 与 `atc-b01` 等等价筛选时使用查询映射并集，旧 ID 仍能解析。螺内酯等多用途药保留多重分类；不得仅凭 ATC 自动推断患者用途。验收覆盖旧分类查询等价、组合筛选、中文搜索、收藏/最近排序和空结果反馈。
